## 0. 结论先行

**实现了什么**

- 独立离线脚本：严格时间解析 → (collected, id) 排序 → 预热 50 篇 + 主评测 1492 篇的严格前 50 篇窗口回放；
  每篇与此前全部 50 篇比较（主评测 74,600 对，未用 top-k，未用向量索引），判定完成后才入窗口。
- 可单独调用的三态比较器 `compare_articles(left, right, config)`：只读白名单字段（不含 story_id），
  输出 label、中文 reason、支持/冲突/未知证据、主体/动作/数值/时间/地址/来源事实槽位，分数明确标注“不是概率”。
  模块声明 `VERSION`/`DEFAULT_CONFIG`，非法 label、空 reason、缺槽位都会报错（单元测试覆盖）。
- 精确基线与事实增强比较器在同一窗口上的对照；保守顺序归组（全部可见成员 same 才加入；多组合格记歧义并新建）；
  逐次入组的支持成员、歧义/受阻原因全部落盘；独立执行核查与标签评测分开。
- 196 对“模型辅助开发核读”标签（实现者逐对阅读原文，不是独立人工金标）、事件家族隔离的 dev/selfheld 划分、
  盲审人工复核模板（含 150 对未标注候选与 393 个多成员组的纯度复核表）。

**真实改善了什么（与精确基线比，同一窗口、同一批标签）**

正例三列依次为“命中 same / 明确误拒 different / 弃权 uncertain”；负例三列依次为“误判 same / 明确 different / 弃权 uncertain”。

**仍错在哪里（详见第 6、7 节与 `error_cases_fact_v4_1_1.md`）**

1. **漏聚合是主要问题，且被保守归组放大**：主评测中比较器判 same 的 1,266 对里，109 对因“多组同时合格”的歧义、
   44 对因“组内其它可见成员不是 same”，最终没进同组；同一事件一旦被早先的弃权拆成两组，后来的逐字重复稿也会
   因歧义另起第三组（级联碎片化）。无标签统计：窗口内 474 对正文逐字一致的稿件，仍有 15 对最终不同组。
2. **窗口限制**：24 对正文逐字一致的转载相隔超过 50 篇（数小时后重发），从未被比较，只能分属不同组。
3. **正例弃权**：BTC 跌破 80000 的三条快照（美元 vs USDT、日内 vs 24H 口径不同）、改写幅度大且共享事实少的报道
   （Coinbase/Amplitude 回应、Pimco 减持 Meta、宇树/红杉“杉宇·创计划”、Ibis、韩国警方立案前调查）。
4. **明确误拒**：dev-v1-170（“联邦基金利率目标下限 3.75%”快讯 vs “美联储维持利率不变”报道，口径/别名未覆盖）；
   无标签抽查（实体/主体互斥判 different 且文本相似度 ≥0.3 的 53 对）中另有 3 对误拒：
   “美股开盘，SK 海力士 (SKHY.O) 涨 8.6%” vs “美股平稳开盘静待FOMC…”，以及两对
   “OKX 与 ICE 拟代币化股票再遭 7 家公司反对” vs “…反对 OKXICE 代币化其股票”（OKX+ICE 与 OKXICE 分词不同）。
5. **同场不同表态**：沃什新闻发布会、皮查伊电话会的不同单句，最终版只能弃权（不会误合并，也不会明确判不同）。

**可用于哪种范围**

- 可用于：离线/人工辅助场景下的**高精度重复稿与改写稿提示**（同一窗口内转载、删节、信息增量），
  以及把三态结果交给人工确认；在本批全部标签与全组核读中，最终版没有发现把不同具体事件合进同一组的情况。
- **不满足全自动使用条件**：(a) 所有标签都由用户公开提供或由实现者本人阅读给出，没有任何独立方保管的未见标签，
  不能证明全量误合并率；(b) 漏聚合与级联碎片化明显，事件组不完整；(c) 语义补充未运行；
  (d) 主体识别依赖通用规则与一张小型中英别名表，遇到别名缺口会误拒或弃权。
  “本批未出现误合并”不代表全量为零，需要先用 `labels/human_review/` 的盲审模板做独立复核。

## 2. 方法

### 2.1 精确基线（exact-1.0.0）
NFKC、空白与通用样板（“X消息，”“X讯”“据X报道，”、结尾短括注）剥离后，正文逐字一致 → `same_event`；
否则 `uncertain`。精确匹配本身没有“不同事件”的证据，因此它从不输出 `different_event`。

### 2.2 文字/事实增强比较器（fact-4.1.1）
**单篇事实抽取**（`facts.py`）：

- 数值：Decimal 精确值 + 原始精度量子；保留负号与货币符号；中文/英文量级（万、亿、万亿、million…）；
  千分位与 NFKC 中文逗号冲突已处理（先保护“数字,三位数字”）；单位分类（美元/USDT/USDC/韩元…、枚+代币、%、点、
  量词…）；**美元与 USDT 不视为同单位**。
- 角色与口径：分句内离数字最近的角色词（现价、阈值、涨跌幅、流入流出、转入转出、买卖、融资、营收、利润、损失、
  估值…）；口径（日内/盘中、24H、1H、同比、季度、累计…）；时间表达（日期、季度、“7 小时前”、“未来 12 个月”）
  先遮蔽，不会被当作数量。
- 主体绑定：数值所在分句的主体短语（角色词之前）、对手方（向X/从X）、行情来源（据 HTX/OKX/Gate…）；
  主体身份 = 非通用拉丁实体 + cashtag + 通用中英别名 + 去掉通用词后的中文核心；绑定不清记 unknown。
- 地址：完整地址/交易哈希与截写/前缀分开；截写只能证明“相容”，不能证明“相同”。
- 结构：综述/合集（连续编号条目、栏目词+长正文）、复合标题、否认/确认立场、“发言主体：表态”。

**配对判定顺序（保守）**：

1. 任一方是综述：只有标题一致且正文高度包含才算同一综述；否则与单事件只记 `uncertain`（不桥接）或无重叠时 `different`。
2. 硬冲突 → `different`：同主体（身份完全一致）、同角色、同单位、同口径、绑定唯一时数值不同或方向相反；
   完整地址不同；截写地址不相容。报价/涨跌幅在来源不同（HTX vs OKX）时不比较冲突。
3. 同模板不同主体 → `different`：双方标题各有对方全文（含别名）完全没有的实体（如 SKHYNIX vs LITE、$TORCH vs $AI），
   且共享锚点不足。
4. 标题主体互斥且互不出现、共享锚点不足 → `different`。
5. 同一发言主体的两条表态各有 ≥50% 内容不见于对方 → 只记 `uncertain`（措辞分歧不是不同事件的证据）。
6. same 需要“事实锚点 + 文本”两类证据：逐字一致；或正文高度包含 + 共享事实/主体；或 ≥2 个独立锚点（锚点分 ≥1.6）+ 中等文本；
   或文本强相似 + 稀有实体 + 锚点；或标题近乎相同 + 主体一致 + 稀有实体/锚点。**单个数量或地址锚点不能独立放行**。
   即使满足，复合报道部分重叠、否认 vs 非否认、行情快照发布相隔 >45 分钟、存在软冲突时仍降为 `uncertain`。
7. 无共享锚点且文本相似度低 → `different`（无共享证据）；其余 `uncertain`。

锚点权重随有效数字位数递减（2119 枚 ETH 强、100 万美元弱）；近似匹配（如 6020 万 vs 6021.78 万）只算弱支持，
**99.99 与 100.00 精度相同不等即冲突，不经舍入判等**。所有门槛都写在 `DEFAULT_CONFIG` 并注明来源
（v1 初值为人工设定；v2–v4 新增项来源于 dev 失败案例，见第 5 节），它们只是证据强度阈值，不是概率。

**背景词频表**：只用回放起点之前采集的 1064 篇文章构建，只用于衡量词项稀有度；不读 story_id，
不含任何被回放文章，不为任何事件提供事实支持。内容 hash 记录在 manifest。

### 2.3 保守顺序归组
加入某临时组必须与该组**当前窗口内全部可见成员**直接 same；任一 different/uncertain 即不合格；
恰好一个组合格才加入，多个合格记 `ambiguous_new` 并新建（不合并旧组、不选最高分或最近组）；
已出窗成员不再提供支持；不做连通分量、多数票或证据传递。每次决定都保存全部窗口支持成员 ID、合格组与受阻组。

### 2.4 story_id 隔离
比较器白名单不含 story_id；回放把文章视图物理裁剪后才交给比较器；审计静态检查比较/归组/回放代码不访问 story_id；
单元测试把相同 story_id 传给两篇不同资产的行情，比较器仍判 different。story_id 只在全部预测完成后用于
`summary.json` 的现状对照（非质量真值）：主评测中预测同组且现状同 story 466 对、预测同组但现状不同 story 647 对、
预测不同组但现状同 story 20 对（多为本实验的级联碎片化，见第 6 节）。

## 11. 已知限制与未覆盖
- 无独立未见标签；全量误合并率未知。
- 漏聚合：比较器弃权 + 保守归组的歧义/受阻 + 窗口限制三者叠加；事件组不完整。
- 主体抽取是通用规则：中文同模板（如两家不同中文公司、无拉丁名）主要靠数值冲突与短语抽取，未专门构造此类难例标签。
- 别名表很小；SKHY.O / SK 海力士、联邦基金利率 / 美联储利率 这类别名缺口，以及 OKX+ICE / OKXICE 这类分词差异，会误拒或弃权。
- 序数（“第13个季度”）表示不准确；“增长103%至307亿美元”中“至”后金额的角色/主体绑定粗糙（不会产生冲突，因冲突要求主体身份一致）。
- 综述识别依赖结构信号；正文被截断的综述可能识别不到。
- 正文可能是采集后的更新版本，无法还原首次入库内容。
